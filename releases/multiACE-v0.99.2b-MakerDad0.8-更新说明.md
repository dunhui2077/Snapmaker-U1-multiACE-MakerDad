# multiACE v0.99.2b-MakerDad0.8 更新说明

- 自动烘干参数区改为 `保存 / 开始 / 停止` 三个按钮。
- 点击“开始”后只启用当前选中的 ACE2 Pro 自动烘干，按钮文案变为“工作”，并显示橙色慢速呼吸闪烁。
- 点击自动烘干区“停止”后只停止当前 ACE2 Pro，开始按钮恢复“开始”和普通样式，停止按钮显示红色慢速呼吸闪烁。
- 手动烘干区的“停止”仍会停用当前 ACE 的自动烘干，必须再次点击自动烘干“开始”才会恢复。
- 自动烘干不再显示手动烘干的剩余时间倒计时。
- 自动烘干配置保存时会清理旧的 `v2_auto_dry_duration` / `v2_auto_dry_duration_N` 参数，不再向用户暴露自动烘干时长。
- 若 ACE 固件内部烘干周期结束但湿度仍高于启动阈值，自动烘干保持“工作”状态并在下一次检查时续上。

已完成 JavaScript、Python、JSON 语法检查及两套固件 overlay 一致性检查。
