# multiACE v0.99.2b-MakerDad0.5 更新说明

## 本次修复

- 修复全局“准许打印温度”对切片软件、Klipper/Fluidd 后台发起打印不生效的问题。
- 打印任务建立和进入打印状态时立即检查所有已连接 ACE2 Pro；任意一台舱温达到或超过全局阈值时，立即停止全部自动烘干并暂停打印。
- 增加 0.5 秒打印中温度守护，覆盖未经过常规启动入口的打印流程。
- 降温到阈值以下后自动恢复打印；取消或结束打印时清理等待恢复状态。
- 修复同一场打印再次超温时可能不再暂停，以及等待期间重复刷相同错误提示的问题。
- Web UI 中按住 ACE 面板空白处时，该 ACE 的连接线临时直连到四个耗材颜色块，并淡化其它 ACE 线路；松开、移出或窗口失焦后恢复默认线路。
- 自动烘干参数区在“保存”后新增独立“启动”按钮：未启动为灰色，启动后为蓝色呼吸闪烁。
- 用户点击手动烘干“停止”后，该 ACE 的自动烘干同时解除待命，湿度变化和再次保存参数都不会重新启动；必须点击“启动”按钮才会恢复。

## 保持不变

- “准许打印温度”仍为一个全局参数，默认 40°C，全部 ACE 共用。
- 每台 ACE 的烘干面板和自动烘干参数仍独立保存。
- 自动烘干风扇固定为 100%，不显示风扇设置。
