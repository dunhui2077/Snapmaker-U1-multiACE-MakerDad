# multiACE v0.99.2b-MakerDad1.0 更新说明

## 本次调整

- 去掉 ACE2 Pro 自动烘干参数区里的“保存”按钮，减少面板拥挤。
- 点击自动烘干“开始”时，会自动保存当前参数：
  - 自动烘干温度
  - 启动湿度
  - 停止湿度
- 参数保存成功后，立即启用自动烘干并执行一次湿度检查。
- 如果配置保存失败，不会启动自动烘干，避免界面显示和配置状态不一致。
